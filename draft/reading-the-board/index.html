An Open Jersey Is Only the Start of the Check

A great card can still have nowhere to go. This 82-0 game board check follows a mid-draft rearrangement, then shows why a move and a swap need different evidence.

🧾Start with the action you are checking

Ordinary placement and rearrangement checks
ActionWhat must be trueCommon false shortcut
Normal new-player pickThe target is empty and appears in the candidate's position list“There is a gap somewhere”
Move an existing playerThe empty target fits the moving card; the board offers the move“Every player can use any empty jersey”
Swap two placed playersBoth cards fit their new destinations“The first card fits, so the swap works”

These checks describe normal picking and rearrangement. An active Trade can offer an occupied destination instead of an empty one; position compatibility still matters. Read which action is active before interpreting the targets.

Incoming candidate: PG / SG. Both of its destinations are occupied. SF and PF are open, but neither matches. All role labels in this practice case are invented.

  1. Look at the placed SG, not just the incoming guard.

    The SG / SF label gives the placed card a second destination. SF is empty in this case.

  2. Return to the board's rearrangement state.

    Tap the selected pool card again to deselect it. Then select the existing SG and use its offered SF target. PG and C stay filled; SG becomes free.

  3. Select the incoming card for the newly open SG.

    Its PG / SG label now matches a free jersey. PF remains open, so the roster still needs another pick.

The useful discovery is the path, not an extra permission. The candidate never gained SF eligibility. An existing player moved legally and opened SG for it. Only perform that path when the real board offers the same roles and targets.

↪️Why that move works

One card travels to an empty target. Its role list answers the compatibility question; there is no second displaced card to check. The destination becomes filled and the source becomes empty.

When selecting an existing jersey for a rearrangement, tapping that source again cancels the selection. Keep the chosen source in mind so a canceled action is not mistaken for a completed move.

🔄Why a similar swap can fail

Imagine SF is occupied by a card labeled SF / PG. The SG / SF card could travel to SF, but the SF / PG card could not travel back to SG. The two-way swap therefore fails its second check.

This is a separate fictional case. Having one flexible card does not make its partner flexible. Write both proposed destinations before treating a swap as available.

🚦Three things to say before the click

  • Source: which selected or placed card am I acting on?
  • Target: which jersey does this action use?
  • Compatibility: which position label permits it—and, for a swap, which label permits the return move?
“Move the SG / SF card to the empty SF; then place the PG / SG candidate at SG.”

A clear sentence is a useful last check in the 82-0 game. If you still cannot find a normal placement, review the whole pool rather than just a narrow search. Use the control reference for browsing, card comparison once the alternatives are legal, and the final-pick guide when only one player is missing.

Check the source, target and position labels before committing the move you have in mind.
